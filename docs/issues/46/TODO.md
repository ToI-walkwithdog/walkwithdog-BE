# 현재 위치 판별 후속 작업

- 위치정보 고지 내용과 필요한 동의 범위를 확정한다. OS 위치 권한 허용과 별도로 해당 절차를 적용한 뒤 실제 카카오 좌표 전송 활성화를 승인한다.
- FE와 위치 권한 안내 시점 및 수동 선택 UX를 확정한다. 개발 환경에서는 Mock으로 지역 선택 흐름을 연결한다.
- 카카오 키 발급 담당, 사용 조건과 호출 한도를 확정하고 승인 후 테스트 키로 수동 연동을 검증한다.
- FE 연동 결과와 운영 지표를 보고 호출 제한, 재시도, 캐시 도입 여부를 검토한다. 좌표 원문을 캐시 키나 값에 사용하지 않는다.
